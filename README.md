# Mack Tella — Portfolio Website

A responsive personal developer portfolio built with plain HTML, CSS, and JavaScript.

## Run locally

1. Download and extract the project folder.
2. Open `index.html` in a modern web browser.

No build tools, package installation, or server are required.

## Customize before publishing

Open `index.html` and update:
- `mackfalinetela@gmail.com` with an email address you want to publish.

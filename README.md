# Mack Tella — Portfolio Website

A responsive personal developer portfolio built with plain HTML, CSS, and JavaScript.

## Run locally

1. Download and extract the project folder.
2. Open `index.html` in a modern web browser.

No build tools, package installation, or server are required.

## Customize before publishing

Open `index.html` and update:
- `YOUR_EMAIL@example.com` with an email address you want to publish.
- The GitHub link (`https://github.com/`) with your actual profile URL.
- The LinkedIn link with your actual profile URL, if you have one.
- Project descriptions and links as your real repositories become available.

The portfolio currently describes project areas and learning interests. Replace these with accurate project details, screenshots, and repository links as your work is completed.

## Files

- `index.html` — page content and structure
- `style.css` — layout, colors, responsive styling, and animations
- `script.js` — mobile navigation and dynamic footer year

## Publish with GitHub Pages

1. Create a GitHub repository, for example `mack-tella-portfolio`.
2. Upload all three website files (`index.html`, `style.css`, `script.js`) and this README.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.

If your GitHub username differs, use that actual username in the profile URL.
